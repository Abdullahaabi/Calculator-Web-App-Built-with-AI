# Jobs To Be Done

**J-1 (R-1).** When I am considering borrowing money, I want to estimate my monthly financial commitment, so I can judge whether the loan is affordable.

**J-2 (R-1).** When I compare financing terms, I want to understand the overall borrowing cost, so I can make an informed decision.

**J-3 (R-2).** When I plan household cash flow, I want to see how debt payments change over time, so I can prepare my budget.
